# DriveLLM

Private browser-based LLM platform built around Google Drive, Google Apps Script, and Google Chrome.

Google Drive stores configuration and knowledge. Apps Script provides the application layer. LLM inference is intended to run locally in Chrome using WebGPU.

The current project requirements and phased plan are in [DriveLLM_Codex_Handoff.md](./DriveLLM_Codex_Handoff.md).
